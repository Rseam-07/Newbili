# Android 开发分支

本分支 `android` 独立推进 Android UI 与功能，基于现有 AndroidFlutter 工程。

手机使用双列封面、分类标签和贴底导航；平板使用主内容与右侧副页。封面展开、预测返回、快速切换与播放器状态保留采用连续转场。设计与验证细节见 [界面说明](MATERIAL_UI_2026-09-15.md)。

每次推送本分支自动运行 Flutter 分析、完整测试、明暗与大字体渲染、三个 ABI 的 Release APK 编译和原生单元测试。CI 候选包在本地沿用现有测试渠道证书重新签名、核验包名/版本/ABI 后，再上传开发预览发布页。

当前应用版本 1.0.10（13）；开发预览单独使用 `android-preview-*` 标签。Material 细节、并发请求与错误恢复见 [可靠性说明](MD_RELIABILITY_2026-09-15.md)。预览不代表已完成实体设备或真实账号验收。
