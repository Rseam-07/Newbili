# Newbili Android 组件预览

打开 `index.html` 可切换手机、平板、副页及动效。图像来自当前 Flutter UI 组件的测试渲染，使用演示内容；不是 Android 真机截图。播放器布局中的示例数据不代表线上评论或实际播放。

- `uwp-phone-light.png` / `uwp-phone-dark.png`：375×812dp。
- `uwp-large-text.png`：320×812dp，两倍系统字体。
- `uwp-tablet-light.png` / `uwp-tablet-dark.png`：1280×812dp。
- `uwp-tablet-compact.png`：1024×812dp。
- `uwp-tablet-pane.png`：主推荐与右侧副页。
- `uwp-tablet-player.png` / `uwp-tablet-player-comments.png`：平板播放布局组件。
- `cover-motion.mp4`：3 秒、25fps，封面展开和返回；渲染器逐帧输出，不是性能测量或实机录屏。
