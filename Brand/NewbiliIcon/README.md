# Newbili 图标源文件

图标以 1024 × 1024 画布设计，保留经典双天线小电视意象，并压缩为最易识别的机身、屏幕与表情三种形状。

## 图层顺序

Icon Composer 只保留两个可编辑前景层：

1. `02-tv.svg`：小电视天线、外壳、屏幕与支脚。
2. `03-face.svg`：两只眼睛与笑脸。

`newbili-icon-master.svg` 是用于 README、宣传和传统 AppIcon 资源的完整矢量母版；`newbili-mark.svg` 使用透明画布，可用于启动页和应用内品牌标记。

图标不再包含装饰线、播放三角形、信号线或半透明气氛层；系统遮罩和轻微深度由 Icon Composer 统一处理。
